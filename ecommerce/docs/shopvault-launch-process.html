ShopVault Website Launch Process

Step-by-step checklist for launching the multivendor ecommerce website.

Important: do not manually edit ecommerce/frontend/build/index.html. That file is generated by React. Make changes in ecommerce/frontend/src/, then run the build command.

Step 1: Finish Core Website Features

  1. Customer can register, log in, log out, and manage profile details.
  2. Vendor can register and log in.
  3. Admin can approve or block vendors.
  4. Vendor can add, edit, delete, and manage products.
  5. Customer can browse, search, sort, and filter products.
  6. Customer can add products to cart and wishlist.
  7. Customer can checkout and pay successfully.
  8. Orders are created only after valid payment confirmation.
  9. Customer can view order history and tracking updates.
  10. Vendor can view and update orders for their products.
  11. Admin can manage users, vendors, products, orders, coupons, and support.

Step 2: Add Required Website Pages

  • About Us
  • Contact Us
  • FAQ
  • Privacy Policy
  • Terms and Conditions
  • Refund Policy
  • Shipping Policy
  • Vendor Policy
  • Help or Support page
  • 404 Not Found page

Step 3: Prepare Real Content

  • Add a real logo, favicon, brand name, and tagline.
  • Add homepage banners, category images, and product images.
  • Replace demo product titles, descriptions, and prices with real catalog data.
  • Add business email, support email, social links, and company address if needed.
  • Write trustworthy policy content for shipping, returns, privacy, and vendor rules.

Step 4: Prepare Backend for Production

  1. Use a strong JWT_SECRET.
  2. Change the default admin password before launch.
  3. Set NODE_ENV=production.
  4. Disable detailed stack traces in public API responses.
  5. Restrict CORS to the production frontend domain.
  6. Add security middleware such as Helmet.
  7. Add rate limiting for login, register, forgot password, and payment routes.
  8. Validate all incoming request data.
  9. Make sure admin, vendor, and customer routes are protected by role.
  10. Add structured logging for errors, orders, payments, and admin actions.

Step 5: Prepare Frontend for Production

  1. Set the frontend API URL to the live backend URL.
  2. Use the live Razorpay key in production.
  3. Check every page on mobile, tablet, and desktop.
  4. Add loading states, empty states, and error messages.
  5. Fix broken links and unused demo routes.
  6. Run the frontend build command.
cd ecommerce/frontend
npm run build

Step 6: Create Production Environment Variables

Backend Example

NODE_ENV=production
PORT=5000
DB_HOST=your_database_host
DB_USER=your_database_user
DB_PASSWORD=your_database_password
DB_NAME=shopvault_production
JWT_SECRET=your_very_strong_secret
JWT_EXPIRES_IN=7d
RAZORPAY_KEY_ID=your_live_razorpay_key_id
RAZORPAY_KEY_SECRET=your_live_razorpay_key_secret
FRONTEND_URL=https://yourdomain.com

Frontend Example

REACT_APP_API_URL=https://api.yourdomain.com/api
REACT_APP_RAZORPAY_KEY_ID=your_live_razorpay_key_id

Step 7: Set Up Production Database

  1. Create a production MySQL database with a hosting provider.
  2. Create a dedicated database user with a strong password.
  3. Add database credentials to backend environment variables.
  4. Run database setup, migrations, or sync process.
  5. Create the production admin account.
  6. Test backend database connection.
  7. Enable automatic backups.

Step 8: Configure Razorpay

  1. Create or verify the Razorpay business account.
  2. Complete KYC.
  3. Generate live API keys.
  4. Add the live key ID to frontend environment variables.
  5. Add the live key ID and secret to backend environment variables.
  6. Test payment success, failure, cancellation, and refund flows.
  7. Add Razorpay webhook handling for reliable production payment updates.

Step 9: Set Up Email Service

Use a provider such as SendGrid, Mailgun, Amazon SES, Brevo, or SMTP.

  • Email verification
  • Password reset
  • Order confirmation
  • Payment success or failure
  • Shipping updates
  • Vendor approval or rejection
  • Support ticket updates

Step 10: Buy and Configure Domain

  1. Buy a domain from a registrar.
  2. Use the main domain for the frontend, for example https://yourdomain.com.
  3. Use a subdomain for the backend, for example https://api.yourdomain.com.
  4. Configure DNS records from the domain provider to your hosting provider.
  5. Enable HTTPS/SSL.

Step 11: Deploy Backend

  1. Choose Render, Railway, DigitalOcean, AWS, VPS hosting, or another Node-capable host.
  2. Set the root folder to ecommerce/backend.
  3. Use npm install as the install command.
  4. Use npm start as the start command.
  5. Add all backend production environment variables.
  6. Deploy and test the API.

Step 12: Deploy Frontend

  1. Choose Vercel, Netlify, Render, or another static frontend host.
  2. Set the root folder to ecommerce/frontend.
  3. Use npm install as the install command.
  4. Use npm run build as the build command.
  5. Set the output folder to build.
  6. Add frontend production environment variables.
  7. Deploy and test the site.

Step 13: Add SEO Setup

  • Page titles and meta descriptions
  • Favicon
  • Open Graph image for link previews
  • robots.txt
  • sitemap.xml
  • Google Search Console
  • Analytics such as Google Analytics or Plausible

Step 14: Final Testing Checklist

  • Register customer
  • Login/logout
  • Forgot password
  • Register vendor
  • Admin approves vendor
  • Vendor creates product
  • Search and filter products
  • Add to cart
  • Checkout
  • Payment success
  • Payment failure
  • Order tracking
  • Wishlist
  • Reviews
  • Support ticket
  • Admin dashboard
  • Mobile responsiveness
  • Page speed
  • Protected route security

Step 15: Launch

  1. Switch Razorpay from test mode to live mode.
  2. Confirm NODE_ENV=production.
  3. Confirm the app uses the production database.
  4. Confirm domain and SSL are working.
  5. Remove demo or test data.
  6. Change default admin credentials.
  7. Announce the website.

Step 16: After Launch

  • Monitor orders and failed payments daily.
  • Review backend errors and server health.
  • Check database backups.
  • Respond to customer and vendor support tickets.
  • Install dependency security updates.
  • Use customer feedback to improve product pages, checkout, and vendor tools.
